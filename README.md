## NVIDIA Riva gRPC

La dependencia del cliente oficial de NVIDIA está fijada en `requirements-riva.txt`. La instalación y la auditoría de parámetros están documentadas en [`NVIDIA_RIVA.md`](docs/NVIDIA_RIVA.md).

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-riva.txt
```
