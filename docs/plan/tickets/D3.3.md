## 2. UI contract

`TaskReviewDialog` shows, before writing:

- title, detail and type;
- due date/time and timezone;
- all-day or timed agenda block with its real start/end;
- the Calendar target from `GET /integrations/status`;
- the pending revision's effective fields when one exists.

`confirm` sends `expected_version` and `revision_id`; `dismiss`/`complete` send
`expected_version`. A `409` reloads the task and integration status, updates the preview
and never confirms automatically. A task without a ready Calendar is shown as
"quedará bloqueada", never as an event already written. The browser never calls Google.
