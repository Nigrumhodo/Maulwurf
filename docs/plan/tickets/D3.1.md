## 1. Scope

| In D3.1 | Not in D3.1 |
|---|---|
| Task list filtered by status and subject | Confirm, dismiss or complete actions |
| `date_status` badge and honest date display | Editing dates or the Calendar block |
| Literal evidence quote linked to the reader | A3.2 persisted `task_evidence` |
| Visible, non-calibrated confidence | Auto-confirmation or Calendar writes |
| Low-ASR-quality warning from `GET /audios/{id}` | Provider calls or audio playback |
| Cursor pagination | D3.2-D3.4 editor/review flows |

## 2. UI behavior

- `/gestion/tareas` renders the live task inbox; the default filter is `needs_review`.
- Filters: task status (all closed vocabulary values) and subject.
- A card shows:
  - title, type, subject and origin;
  - task `status` and `calendar_sync_status` as separate contract badges;
  - `date_status` (`resolved`, `ambiguous`, `missing`) plus the resolved date or the
    original `date_text`/`date_reason`;
  - confidence (`0.92` or `sin confianza`) with a note that it is not calibrated;
  - a pending-revision badge when present;
  - the literal quote and `ver cita en la clase` to
    `/biblioteca/{audio_id}?segment={segment_id}`;
  - a class-level ASR warning (`baja confianza`, `segmentos vacíos`, `repeticiones`) with
    counts; if the detail read fails, an explicit “no disponible” state.
- A manual task with no source shows “sin cita textual” and never fabricates a link.
- No audio player, download, confirmation or Calendar action exists on the page.

## 5. Browser evidence (C-S3-DA-01)

Local stack, synthetic session and seeded tasks (no private audio or class text):

- `/gestion/tareas` rendered the `needs_review` tasks (resolved and ambiguous) from the
  real `GET /tasks` API.
- The page showed `needs_review`, `resolved`, `ambiguous`, `confianza 0.92`,
  `calidad ASR baja`, and `baja confianza (2/5)`.
- Clicking `ver cita en la clase` opened
  `/biblioteca/{audio_id}?segment={segment_id}` and the reader marked the segment
  `aria-current="location"`.
- The `/tasks` response carried `Cache-Control: no-store`.
- No `audio`/`video` element, page error or console error was observed.
