## 2. Contract

`TaskEvidenceOut` adds `ordinal` (the persisted `segments.ordinal`). It is additive and
lets the task link show `segmento N` without guessing.

The link target remains
`/biblioteca/{audio_id}?segment={segment_id}`. The reader already validates and highlights
that anchor; D3.4 does not add a second route.

## 3. UI behavior

- The evidence quote stays above the link.
- `TranscriptLink` shows `ver 0:05` only when the reader metadata says the times are
  reliable: `timestamp_precision` is `word|segment`, both offsets are finite,
  `0 <= start < end`, and the end is inside the class duration.
- Otherwise it shows `ver segmento N`.
- If the class detail is unavailable, it falls back to the ordinal rather than showing a
  timestamp that cannot be verified.
- A task without a class/source renders no link.
- The visible link is bordered, compact and uses the existing mint/lavender palette.
