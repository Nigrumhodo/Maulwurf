| Pending revisions discarded on close | `POST /tasks` |

## 2. Rules

- `dismiss`: `pending`, `needs_review` and `confirmed` -> `dismissed`.
- `complete`: `confirmed` -> `completed`.
- Repeating the same command with the current version is an accepted no-op; a stale
  version is `409 version_conflict`; an illegal transition is `409 invalid_transition`.
- Another tenant's task is `404`.
- Every effective transition bumps `tasks.version`; `notifications.status='pending'`
  rows of the task are cancelled; the linked Calendar event is not touched.
- `pending_confirmation` revisions of the closed task are marked `discarded` in the same
  transaction.
