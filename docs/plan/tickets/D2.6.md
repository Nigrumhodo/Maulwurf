## 3. Infra: same-origin chat

`infra/Caddyfile` did not route `/chat`, so requests fell through to the SPA. A dedicated
matcher now forwards `/chat` and `/chat/*` to `api:8000` with `flush_interval -1` and the
same 10 MB JSON body ceiling as the other API routes. `caddy validate` passes and an
unauthenticated `GET https://localhost/chat/conversations` reaches the API (`401 JSON`)
instead of the static SPA.

## 4. Provider options

### Deterministic local evidence (used here)

The local demo uses the existing J2.6 `e2e-provider` double for embeddings and streaming chat,
plus one synthetic indexed class. No provider key and no private data are involved. The double
is not provider-contract evidence.

### Real provider (optional)

The current `.env` has no supported LLM/embedding values. To use a real OpenAI-compatible
provider, configure:

```text
MAULWURF_LLM_BASE_URL
MAULWURF_LLM_API_KEY
MAULWURF_LLM_MODEL
MAULWURF_LLM_MODEL_WINDOW
MAULWURF_D3_TEXT_CLOSED_MODELS

MAULWURF_EMBEDDING_BASE_URL
MAULWURF_EMBEDDING_API_KEY
MAULWURF_EMBEDDING_MODEL
MAULWURF_EMBEDDING_DIMENSION=1536
```

`MAULWURF_DEEPSEEK_*` is not a supported settings schema in this revision. The real smoke
would use one synthetic question, no private class text, no prompt/response logging, and only
after the provider quota is confirmed.

## 6. Streaming behavior

1. Create or select a conversation; the mode is fixed by the conversation.
2. Generate `client_message_id` once per logical turn and keep it only in memory.
3. Append the user question and an assistant placeholder.
4. POST with `fetch`; parse `snapshot`, `delta`, `citation`, `done`, `error`; heartbeats are
   ignored.
5. `snapshot` supplies the assistant id; `delta` appends; citations keep the server label;
   only `done|error` is terminal.
6. EOF without a terminal is not success: fetch history, replace the optimistic turn, and do
   not resend automatically.
7. Cancel aborts the fetch, calls the cancel API with the snapshot id, keeps the partial and
   refreshes history. A new client key is required for an explicit retry.
8. Conversation/history pagination uses the opaque cursors; older messages are prepended.

| Risk | Mitigation |
|---|---|
| `/chat` falls into the SPA | Dedicated Caddy matcher; validated with a real request |
| SSE buffering | `flush_interval -1`; response `no-store` preserved |
| Stream cut looks complete | EOF is non-terminal; reconcile from history |
| Duplicate question on recovery | Stable in-memory `client_message_id`; no automatic resend |
| Mode/scope mismatch | Build the exact mode body; server `chat_mode_invalid` is displayed |
