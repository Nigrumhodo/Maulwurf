## 2. Contract addition (area A)

A2.9 exposed detail, TXT, SRT and progress but no segment list. The reader needs stable
segment ids and offsets, so `GET /audios/{audio_id}/transcript` was added:

```json
{
  "audio_id": "uuid",
  "version": 1,
  "timestamp_precision": "word|segment|none",
  "char_count": 120,
  "summary": "text or null",
  "topics": ["topic"],
  "analysis_version": 1,
  "segments": [
    {
      "id": "uuid",
      "ordinal": 1,
      "text": "segment text",
      "char_start": 0,
      "char_end": 24,
      "t_start": 0.0,
      "t_end": 5.0
    }
  ]
}
```

The route is owner-scoped, `no-store`, returns only the active live transcript and never
exposes audio or storage locations. `summary`, `topics` and `analysis_version` are copied
from the existing active transcript row; no new value is derived.

## 3. Fixed decisions

1. **Times are conditional.** They are displayed only when `timestamp_precision` is
   `word|segment`, both offsets are finite, `0 <= start < end`, and the end is within the
   class duration. Otherwise the UI prints `segmento N`.
2. **No invented summary.** `analyze=not_requested` renders an empty summary note, not a
   generated sentence. Pending/failed states are explicit.
3. **Stable links, no credentials.** Segment links are `/biblioteca/{audio_id}?segment={id}`;
   authorization remains the session cookie.
4. **Exports remain server-owned.** TXT is a direct text attachment; SRT is fetched only
   after `exports.srt`, and a racing `409 srt_unavailable` disables the button honestly.
5. **No raw HTML.** Segment text and summary are React text nodes.

## 7. Risks

| Risk | Mitigation |
|---|---|
| Times present but not reliable | Central validator; fallback to ordinal |
| Unknown `?segment=` | Explicit notice, no highlight |
| SRT race | `409 srt_unavailable` disables and explains |
| Summary not requested | Empty note, never generated content |
| Citation route drift | Canonical `/biblioteca/{audio_id}` is implemented |
| Large transcript | Server orders segments; UI renders text nodes without parsing HTML |
