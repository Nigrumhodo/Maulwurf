## 1. Scope delivered

| In this slice | Not in this slice |
|---|---|
| Summary, topics, analysis version and ASR warnings | Audio playback |
| Aggregate, attempt, index and analyze statuses | New ingestion or retranscription |
| Detected items filtered by class | Editing tasks from the class page |
| Visible backfill/reanalysis action | Real provider call |
| `GET /tasks?audio_id=` and `POST /audios/{id}/analysis/backfill` | S3.1 ownership closure |

## 2. Contract additions

- `GET /tasks` accepts `audio_id` (tenant-scoped) so the class page can show only its own
  detected items.
- `POST /audios/{id}/analysis/backfill` queues analysis over persisted text through
  `analysis_backfill.backfill_audio(..., apply=True)`.
  - `202` for `queued`/`already_queued`.
  - `200` for `already_analyzed`.
  - `404` foreign/missing class.
  - `409 transcript_unavailable` without usable text.
  - `409 invalid_transition` for cleanup pending, revoked owner, F2-without-run or unknown
    state.
- `LibraryAudioDetail.analysis_backfill_available` is now typed in the web client.

The endpoint is the HTTP surface of the existing S3.1 service. S3.1 remains owned by its
current claimant; this ticket records the endpoint as a D3.5 dependency and does not
transfer the claim.

## 3. UI behavior

- `ClassStatus` shows aggregate, attempt, index and analyze states, plus cleanup pending.
- `analysis_backfill_available` exposes one action:
  - `not_requested` -> "analizar esta clase";
  - `failed`/`cancelled` -> "reintentar análisis";
  - previous version -> "re-analizar con la versión actual".
- A failed index has its own "reintentar índice" action.
- Both actions say they use persisted text only; neither uploads audio.
- `ClassSummary` shows the persisted summary, topics, analysis version and ASR warnings.
  `not_requested`/pending/missing summaries are explicit and never generated.
- `ClassItems` lists the class tasks, active first, with status, due date and the D3.4
  evidence link; it links to `/gestion/tareas` for review.
- `TranscriptReaderPage` loads detail, transcript and tasks; a tasks failure is isolated
  and does not hide the class text.
- No `<audio>`, signed audio URL, reupload or retranscription exists.
