cuenta. No dice si este `Recognize` retiene audio o texto, por cuánto
tiempo, en qué región ni con qué base de consentimiento. Eso bloquea
grabaciones reales. D3-Texto queda fuera de este spike.

## D4

payload, duración, cuota ni deadline del servidor. 200 MiB y 3 h siguen
sin aprobar. El coste por minuto y por hora es `NO VERIFICADO`.

## D6

La propuesta es `none` porque las dos llamadas con offsets devolvieron
0 palabras y 0 segmentos. Dejarla `pending` evita presentar esa
propuesta como G2-X. Aprobar `none` exigiría, en la misma revisión,
`timestamp_precision=none`, tiempos null y la spec, la API y la UI
alineadas. Eso no ocurre aquí.
