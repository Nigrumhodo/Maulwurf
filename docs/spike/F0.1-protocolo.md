# F0.1 spike protocol (L1.3)

Unique format of the NVIDIA contract report. The S1.A8 artifact is
[`F0.1-informe-riva.md`](F0.1-informe-riva.md) (it does not exist yet). A report that does
not follow these sections **does not close F0**.

Norms: [PLAN_IMPLEMENTACION.md](../PLAN_IMPLEMENTACION.md) §3 F0.1,
[plan/S1.md](../plan/S1.md) S1.A2–A8, [NVIDIA_RIVA.md](../NVIDIA_RIVA.md),
[PLAN_TESTS.md](../PLAN_TESTS.md) P-S1-SG-07/08.

An unobserved datum is recorded **`NOT VERIFIED`**. A gap, a mock, or a
silence is never presented as approval.

## 1. Environment and versions

The report opens with:

| Field | Content |
|---|---|
| Date (UTC) | instants of the P- calls |
| Machine / OS | e.g. WSL; no extra sensitive hostname |
| Python | 3.12 ([ADR-0002](../adr/ADR-0002-versiones.md)) |
| `nvidia-riva-client` | `==2.27.0` |
| gRPC / protobuf | resolved versions (observed, not invented) |
| Server | `grpc.nvcf.nvidia.com:443` + TLS |
| `function-id` | `b702f636-f60c-4a3d-a6f4-f3568c13bd7d` |
| Server version | the one the endpoint answers with, or `NOT VERIFIED` |
| Budget | authorized cap (minutes/USD); protected account, **no** secret or key names |
| Audio | synthetic S1.A1 in RAM; known expected text |

Local `max-message-length` up to `1073741824` is a client cap, **not** a
promise that the endpoint accepts 1 GiB.

## 2. Redaction

Forbidden in git, CI, public logbooks, and the report:

- `NVIDIA_API_KEY`, `Bearer …`, `authorization` metadata
- audio, WAV, raw payloads, transcripts of real voices
- PII

Allowed: argv/call schema with `Bearer $NVIDIA_API_KEY`; gRPC codes;
metrics; synthetic expected text; quotes of the NVIDIA terms (public URL).

Transcribe, do not translate. Explicit language. No `task:translate` or
fallback `multi`. Bearer only in the backend.

## 4. Closure criteria (S1.A9 uses this table)

Each decision: `approved` \| `blocked` \| `pending`, role, date (UTC), evidence
(report section). `blocked` is not approval.

| Decision | Approved only if | If it fails |
|---|---|---|
| **D2** Riva contract | Versioned report with §1–§3.1–3.4; languages/formats/limits/errors observed or explicit `NOT VERIFIED` | Do not enable real ingestion or constants in capabilities |
| **D3-Audio** | Endpoint terms: what is retained, for how long, region/sub-processors, consent. Cited sources | Only synthetic in RAM; **blocks real classes** |
| **D4** Capacity | Measured limits and deadlines. 200 MiB / 3 h **not** approved until the benchmark | Lower capabilities with approval; do not use disk |
| **D6** Temporal alignment | Exactly `word` or `segment` (G2-T) **or** `none` (G2-X). Zero invented times | Spec, API, and UI in the **same** review; no silent fallback |

D3-Text (LLM/embeddings) is **not** closed in this spike.

## 5. Shape of the S1.A8 artifact

Path: `docs/spike/F0.1-informe-riva.md`. Metric annexes in the same
directory, without audio. Planned scripts: `scripts/provider/riva_*.py`
(S1.A2–A7); Bearer only via the environment.

1. Environment and versions (§1 of this protocol)
2. Redaction applied (§2)
3. Capability matrix (languages, formats, sample rate, limits)
4. Timestamps and D6 proposal
5. Latency, memory, cost
6. NVIDIA contract review (D3-Audio)
7. D2 / D3-Audio / D4 / D6 table with status
8. Annexes: redacted commands, gRPC codes, numeric tables
