# RAM budget per slot (S1.B2)

Date (UTC): 2026-09-27. WSL. It does not approve 200 MiB or 3 h. D4 remains `blocked`.

## Formula

A slot is the original + active fragments + the ffmpeg buffer + the SDK buffer + margin.

The PCM of 3 h at 16 kHz mono s16 is 345600000 bytes. It does not fit in the slot:
ingestion does not decode the whole 3 h. A 1 s fragment at 16 kHz mono s16
is 32000 bytes.

## Compose provisionals

| Limit | Bytes | Origin |
|---|---|---|
| Upload | 209715200 | `INGEST_MAX_UPLOAD_BYTES` (200 MiB) |
| tmpfs | 268435456 | `INGEST_TMPFS_BYTES` (256 MiB) |
| Slots | 2 | `INGEST_SLOTS` |
| Container memory | 1073741824 | `INGEST_MEM_LIMIT` (1 GiB) |

With the ffmpeg and SDK buffers at 0 (still `NO VERIFICADO` for a 200 MiB
file):

| Budget | Bytes | Fits in the 256 MiB tmpfs |
|---|---|---|
| One slot (200 MiB + 1 fragment) | 209747200 | yes, arithmetically |
| Two slots | 419494400 | no |

Two slots of files (419494400 bytes) plus two copies of the upload in the
process heap (419430400 bytes) add up to 838924800. That is still less
than 1 GiB, but it does not include the child ffmpeg peak or the SDK for a
200 MiB file. Fitting in 1 GiB remains `NO VERIFICADO`.
