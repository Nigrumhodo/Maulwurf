## 6. Revisión contractual (D3-Audio)

Fuente pública consultada, no una medición de este `function-id`:

- [Service Specific Terms for NVCF Service](https://www.nvidia.com/en-us/agreements/cloud-services/service-specific-terms-for-nvcf-service/)

Esa página, en su sección de datos, dice que NVIDIA recoge datos de
configuración y sistema operativo, métricas de carga (ejecuciones y
tiempo de GPU) y logs de error y de ejecución para traza y diagnóstico.
Indica que esos logs se pueden borrar a elección del cliente y que se
asocian a la cuenta de empresa. Pide nombre, correo o datos de
habilitación para entregar el servicio. Remite el tratamiento a un DPA
que este informe no transcribe.

Eso no dice, para el `Recognize` de este `function-id`:

| Pregunta | Estado |
|---|---|
| Si retiene el audio enviado | `NO VERIFICADO` |
| Si retiene el texto devuelto | `NO VERIFICADO` |
| Cuánto tiempo | `NO VERIFICADO` |
| Región y subprocesadores | `NO VERIFICADO` |
| Base de consentimiento para voces de clase | `NO VERIFICADO` |

Sin esa garantía, solo se acepta audio sintético en RAM. Las clases
reales siguen bloqueadas. D3-Texto (LLM y embeddings) no se cierra aquí.
