[`F0.1-informe-riva.md`](F0.1-informe-riva.md) (aún no existe). Un informe que no

Normas: [PLAN_IMPLEMENTACION.md](../PLAN_IMPLEMENTACION.md) §3 F0.1,
[plan/S1.md](../plan/S1.md) S1.A2–A8, [NVIDIA_RIVA.md](../NVIDIA_RIVA.md),
[PLAN_TESTS.md](../PLAN_TESTS.md) P-S1-SG-07/08.

Un dato no observado se registra **`NO VERIFICADO`**. Nunca se presenta un
hueco, un mock o un silencio como aprobación.

## 1. Entorno y versiones

El informe abre con:

| Campo | Contenido |
|---|---|
| Fecha UTC | instantes de las llamadas P- |
| Máquina / OS | p. ej. WSL; sin hostname sensible de más |
| Python | 3.12 ([ADR-0002](../adr/ADR-0002-versiones.md)) |
| `nvidia-riva-client` | `==2.27.0` |
| gRPC / protobuf | versiones resueltas (observadas, no inventadas) |
| Servidor | `grpc.nvcf.nvidia.com:443` + TLS |
| `function-id` | `b702f636-f60c-4a3d-a6f4-f3568c13bd7d` |
| Versión de servidor | la que responda el endpoint, o `NO VERIFICADO` |
| Presupuesto | tope autorizado (minutos/USD); cuenta protegida, **sin** nombres de secretos ni claves |
| Audio | sintético S1.A1 en RAM; texto esperado conocido |

`max-message-length` local hasta `1073741824` es cota del cliente, **no**
promesa de que el endpoint acepte 1 GiB.

## 2. Redacción

Prohibido en git, CI, bitácoras públicas y el informe:

- `NVIDIA_API_KEY`, `Bearer …`, metadata `authorization`
- audio, WAV, payloads crudos, transcripts de voces reales
- PII

Permitido: argv/esquema de llamada con `Bearer $NVIDIA_API_KEY`; códigos gRPC;
métricas; texto esperado sintético; citas de términos NVIDIA (URL pública).

Transcribir, no traducir. Idioma explícito. Sin `task:translate` ni fallback
`multi`. Bearer solo en backend.

## 3. Mediciones

Cada fila alimenta P-S1-SG-07 salvo latencia/memoria/coste (P-S1-SG-08).

| Sección del informe | Qué medir | Ticket |
|---|---|---|
| 3.1 Idiomas | Candidatos uno a uno (español incluido). Negativos: código inválido, ausente, audio ≠ declarado. Allowlist propuesta para A2.2 | S1.A3 |
| 3.2 Formatos | Línea base WAV PCM s16 mono. ffprobe/ffmpeg: mp3, m4a, wav, ogg, opus, flac, webm. Tabla contenedor/codec/canales → aceptar/rechazar. Sample rate efectivo (16 kHz candidato) | S1.A4 |
| 3.3 Límites | Payload, duración, cuota, concurrencia, deadlines, cancelación, errores gRPC. Sin saturación no autorizada | S1.A5 |
| 3.4 Offsets | Pedir word y segment. Unidades, orden, rango, frases/silencios/fronteras. `global = offset_fragmento + local` sin duplicar overlap. Propuesta `word\|segment\|none` | S1.A6 |
| 3.5 Rendimiento | Latencia por duración/idioma; RSS del SDK; pico PCM (3 h 16 kHz mono s16 ≈ 330 MiB crudo — medir); coste/min y /h | S1.A7 |

## 4. Criterios de cierre (S1.A9 usa esta tabla)

Cada decisión: `approved` \| `blocked` \| `pending`, rol, fecha UTC, evidencia
(sección del informe). `blocked` no es aprobación.

| Decisión | Se aprueba solo si | Si falla |
|---|---|---|
| **D2** Contrato Riva | Informe versionado con §1–§3.1–3.4; idiomas/formatos/límites/errores observados o `NO VERIFICADO` explícito | No habilitar ingesta real ni constants en capabilities |
| **D3-Audio** | Términos del endpoint: qué retiene, cuánto, región/subprocesadores, consentimiento. Fuentes citadas | Solo sintético en RAM; **bloquea clases reales** |
| **D4** Capacidad | Límites y deadlines medidos. 200 MiB / 3 h **no** está aprobado hasta el benchmark | Bajar capabilities con aprobación; no usar disco |
| **D6** Temporalidad | Exactamente `word` o `segment` (G2-T) **o** `none` (G2-X). Cero tiempos inventados | Spec, API y UI en la **misma** revisión; sin fallback silencioso |

D3-Texto (LLM/embeddings) **no** se cierra en este spike.
