# Spanish archive

Frozen copy of the project documentation in its original Spanish, kept for historical
reference. **Do not edit these files.** The canonical documentation is in English, at the
same relative paths one level up (for example `docs/es/ARCH.md` ↔ [../ARCH.md](../ARCH.md)).

- Only the relative links inside this archive were adjusted; the content is unchanged.
- It reflects the repository as of 2026-10-09 and is not updated afterwards, so it can be
  out of date with respect to the English documentation.
- Spanish literals that code or tests still emit (for example `NO VERIFICADO`) are kept as is
  in the English documentation as well.
