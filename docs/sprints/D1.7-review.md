## Scope

Static drafts with no wiring (`apps/web`):

- `src/components/upload/UploadForm.tsx`: subject, class date, timezone and audio language
  (no preselection), optional title/teacher, versioned consent `2026-09-19` with two
  mandatory acknowledgements, permanent "audio not kept" notice, and a mock error state.
- `src/pages/SubirClasePage.tsx`: renders the upload form.
- `src/pages/BibliotecaPage.tsx`: per-stage badges (audio attempt, index, analysis) plus the
  aggregate, the permanent "audio not kept" notice, and differentiated actions
  ("upload again" vs "retry analysis/index").

No bytes are sent and no API is called; D2.1/D2.4 consume these decisions.

## UX decisions (artifact)

1. Consent is versioned (`2026-09-19`) and shown in full; submit stays disabled until both
   acknowledgements are checked.
2. The audio language has no preselection.
3. "Audio not kept" is a permanent notice, not a dismissible toast.
4. The library shows the raw contract value per stage plus the derived aggregate.
5. Cleanup-pending blocks indexation and does not offer re-upload; a missing transcript
   offers "volver a subir", while a kept transcript offers "reintentar análisis/índice".
