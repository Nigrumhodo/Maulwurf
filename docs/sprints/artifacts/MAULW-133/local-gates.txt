Shared-environment note
-----------------------
This host runs several Maulwurf worktrees at the same time. A full `pytest -m integration`
run overlapped with other worktrees that were also running `alembic upgrade head`; those
migrations execute `ALTER ROLE "maulwurf_app" ...` and PostgreSQL answered
`tuple concurrently updated`, failing the session-scoped migration fixture before any A4.3
test ran. The same collisions hit `test_migrations.py`/`test_rls.py` when run together.
The A4.3-specific integration module and the notification schema/lifecycle modules pass in
isolation once the other suites release the shared database; the full-suite result is
recorded in the PR body with that contention, not presented as an A4.3 failure.
