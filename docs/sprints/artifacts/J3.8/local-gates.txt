Known pre-existing integration failures
---------------------------------------
All 32 failures are in test_search.py (11), test_chat_sse.py (17) and test_g4_eval.py
(4). They require `SET LOCAL hnsw.iterative_scan`, which needs pgvector >= 0.8; this
sandbox has pgvector 0.6.0, so the API answers the documented
`500 search_hnsw_unsupported`. They are outside this diff and match the J3.7 baseline.
The new I-S3-JF-07 module (19 cases) and the 84 J3.7/migration/RLS/isolation cases pass.

Environment note
----------------
The local Redis 7 was started with the distribution defaults (`save` enabled), which made
`test_redis_policy.py` fail on the first full run. Applying ADR-0005 (`CONFIG SET save ""`)
and flushing the leftover search quota keys made both cases pass; the second full run above
used that configuration. This is environment setup, not an application change.
