Environment note
----------------
The sandbox exports a NO_PROXY value containing bracketed IPv6 literals (`[::1]`).
httpx parses that list incorrectly, which breaks two pre-existing unit tests
(`test_ingest_sink.py::test_sink_is_the_ingest_client_when_configured` and
`test_llm.py::test_shared_http_client_is_bounded_reused_and_closed`). They pass with a
syntactically valid NO_PROXY, which is how the counts below were produced. This is an
environment issue outside this diff, already recorded by J3.4/J3.5.
