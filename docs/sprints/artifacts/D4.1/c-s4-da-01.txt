4. Real-stack bug found and fixed (unblocking A4.2)
   The first PATCH answered 500 internal_error. The API log and a direct reproduction
   showed MissingGreenlet at `_preferences_out` reading `updated_at`: the column is an
   `onupdate` server default and SQLAlchemy expires it after the flush, so the lazy load
   ran outside greenlet_spawn.
   Fix: `apps/api/app/services/notification_center.py` now runs
   `await db.refresh(row, ["updated_at"])` after `await db.flush()`.
   The existing integration test `test_patch_updates_only_the_sent_fields_and_persists_them`
   passed before and after because it reuses the test transaction; the local compose
   request reproduced the failure and the same request now succeeds.
   API image rebuilt for api/worker/scheduler; the browser save above is the post-fix run.
